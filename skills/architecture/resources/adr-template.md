# Architecture Decision Record

## Title
ADR-NNN: <decision>

## Status
Proposed | Accepted | Superseded

## Context
What project facts, constraints, versions and requirements force a decision?

## Decision
What is being chosen?

## Alternatives considered
What credible alternatives were rejected and why?

## Consequences
Positive, negative and operational consequences.

## Verification
How will we know this architecture works?

## Migration / rollback
How can the project move from the old approach or undo this decision?
